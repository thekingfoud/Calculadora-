   Descripción del proyecto

Este proyecto consiste en el desarrollo de una calculadora web interactiva utilizando HTML, CSS y JavaScript, aplicando los fundamentos de programación vistos en el módulo.

La aplicación permite realizar operaciones matemáticas básicas, mostrar resultados en pantalla en tiempo real y mantener un historial de operaciones realizadas.

El objetivo principal del proyecto fue aplicar conceptos como funciones, eventos, manipulación del DOM, estructuras de datos y modularización del código.


  
  Funcionalidades

Operaciones básicas:

Suma (+)

Resta (-)

Multiplicación (*)

División (/)

Interfaz visual interactiva.

Visualización de operación actual y resultado.

Historial de operaciones recientes.

Soporte para teclado físico.

Eliminación de números ingresados.

Reinicio de la calculadora.

Modo interactivo mediante prompt() solicitado en la actividad.

   Estructura del proyecto
Calculadora/
│
├── index.html          → estructura de la aplicación
├── style.css           → estilos visuales
│
└── js/
    ├── calculadora.js  → lógica matemática y estado

El proyecto está organizado de forma modular para facilitar su mantenimiento y escalabilidad.



   Tecnologías utilizadas

HTML5

CSS3

JavaScript (ES6)

Manipulación del DOM

Programación orientada a objetos (clases)



  Decisiones de desarrollo

Se separó la lógica de la interfaz para mejorar la organización del código.

Se utilizó programación orientada a objetos para manejar el estado de la calculadora.

Se implementó delegación de eventos para optimizar el manejo de botones.

Se diseñó una interfaz simple y clara enfocada en la experiencia del usuario.
